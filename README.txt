DATE-UMFRAGE – HOSTING

1. Lade index.html in ein GitHub-Repository hoch.
2. GitHub: Settings -> Pages -> Deploy from a branch.
3. Branch main und Ordner / (root) auswählen und speichern.
4. GitHub zeigt danach eine öffentliche URL an.
5. Diesen Link kannst du direkt per WhatsApp schicken.

Alternative: Die index.html bei einem statischen Hoster wie Netlify veröffentlichen.

Wichtig: WhatsApp führt HTML nicht innerhalb des Chats aus. Die Seite muss über eine öffentliche URL im Browser geöffnet werden.
